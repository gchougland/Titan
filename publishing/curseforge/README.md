# Titan CurseForge page kit

Open `preview.html` to see the complete layout. All artwork is flat, editable vector geometry, with PNG copies for placing in the description. The five gameplay screenshots were supplied by the author.

## Listing summary

Colossal boss fights, climbable giants, an underground crypt, and a walking house companion. Explore Hytale on a much bigger scale.

## Put the page together

1. Use `description.md` as the writing master, or `description.html` as a simple HTML fragment if your editor accepts HTML. The preview styling is only for local review.
2. The description files already use the six hosted banner URLs. The preview keeps local banner copies for convenient review.
3. Five hosted screenshots are included beneath their matching descriptions, in order: Talus, Roaming Temple, Dunewyrm, crypt, and Baba Yaga House. Captions sit directly beneath the images and can be omitted. `screenshots.json` records the links; a group screenshot remains optional.
4. Check the saved description at desktop and narrow widths. No visible screenshot instructions remain in the listing copy.

## Artwork

- `00-titan`: title banner, 1400 x 420.
- `01-titans` through `05-party`: section headers, 1400 x 180.
- Every banner has an editable `.svg` and a matching `.png` export.
- Palette: charcoal `#192127`, slate `#263239`, ivory `#F1EFE5`, gray green `#AAB7B4`, and muted lime `#C1D59B`.
- SVG lettering uses Arial Bold and Arial. Keep those fonts available when editing; convert lettering to outlines in your vector editor before sending to someone who needs font-independent artwork.
- Symbols are abstract chapter markers, not renders of the in-game models.
- These assets were constructed from vector primitives and typography. The earlier detailed generated concept is not used anywhere in this kit.

The local preview needs an internet connection for the hosted screenshots, but no external fonts or scripts. Nothing has been published to CurseForge.
